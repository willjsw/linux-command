## 해설

**1. ①** BSD·MIT 는 허용형(permissive) 라이선스로 소스 비공개 파생·상용 배포가 가능. GPL·AGPL 은 강한 카피레프트, LGPL 은 라이브러리 링크에 한해 완화된 카피레프트.

**2. ①** systemd 의 `multi-user.target` 이 SysV 런레벨 3(텍스트 다중 사용자)에 대응. `graphical.target` 은 런레벨 5(GUI), `rescue.target` 은 단일 사용자에 대응.

**3. ④** ext2 는 저널이 없어 비정상 종료 시 `fsck` 전수 검사가 필요. ext3·ext4·xfs·btrfs 는 모두 저널링(또는 CoW) 지원 → [[mount]].

**4. ④** `export VAR` 로 셸 변수를 환경변수로 승격해야 자식 프로세스가 상속. `set` 은 셸 변수·옵션 표시, `env` 는 환경변수 출력·일시 설정 → [[env]].

**5. ③** `2>&1` 은 표준에러(2)를 표준출력(1)이 향하는 곳으로 복제. 리다이렉션 순서상 `> result.log` 뒤에 와야 둘 다 파일로 감. `&>` 는 bash 축약으로 여기서는 `/dev/null` 로 폐기.

**6. ④** `^` 는 행의 시작 앵커 → `^error`. `$` 는 행의 끝, `\<` 는 단어 시작 경계, `.` 는 임의 한 문자 → [[grep]].

**7. ②** `s/찾을것/바꿀것/g` 에서 `g`(global) 플래그가 행 내 모든 일치를 치환. `g` 없으면 행마다 첫 일치만. `y` 는 문자 단위 변환 → [[sed]].

**8. ②** `$3` 은 세 번째 필드, `{print $3}` 로 출력. `$0` 은 전체 행. 기본 구분자는 공백·탭 → [[awk]].

**9. ①** SIGKILL(9)·SIGSTOP(19)만 프로세스가 무시·차단·핸들링 불가. `kill` 기본 시그널은 SIGTERM(15)으로 정상 종료 요청 → [[kill]].

**10. ②** `DISPLAY=호스트:디스플레이번호.화면` 형식. 원격 X 출력은 `export DISPLAY=host:0` 로 지정. X 는 서버가 화면, 클라이언트가 응용을 담당하는 역구조.

**11. ③** 250 호스트에는 사용 가능 호스트가 250 이상이어야 함. `/24` = 2^8 - 2 = 254 로 충족. `/25` 는 126 으로 부족.

**12. ①** IMAP 143, POP3 110, SMTP 25. 993 은 IMAPS(TLS), 995 는 POP3S → [[network-service]].

**13. ③** IPv6 는 128비트(IPv4 는 32비트). 16비트씩 8그룹을 콜론 구분 16진수로 표기.

**14. ②** crontab 필드는 `분 시 일 월 요일`. 일요일 3시 → `0 3 * * 0`. 요일 0 과 7 모두 일요일이나 분·시 자리 순서가 핵심 → [[crontab]].

**15. ④** `-a`(append)를 `-G` 와 함께 써야 기존 보조 그룹 유지. `-G` 단독은 나열한 그룹으로 **교체**, `-g` 는 기본 그룹 변경 → [[usermod]].

**16. ③** PV(물리 볼륨)를 모아 VG(볼륨 그룹)라는 저장 풀을 만들고, 그 안에서 LV(논리 볼륨)를 잘라 씀. PE 는 VG 의 할당 단위 → [[lvm]].

**17. ①** 로그인 실패는 `/var/log/btmp` 에 기록되고 `lastb` 로 조회. wtmp-last(성공·재부팅), utmp-who(현재 접속), lastlog(마지막 로그인)는 실패 이력이 아님 → [[system-security]] 1-1 · [[last]].

**18. ③** `DocumentRoot` 가 웹 문서 루트(`/var/www/html`). `ServerRoot` 는 설정·로그 기준 디렉터리, `DirectoryIndex` 는 기본 문서, `UserDir` 은 사용자 홈 웹 디렉터리 → [[network-service]] 1-1.

**19. ③** `-P`(Policy)로 체인 기본 정책 지정. `-A` 는 규칙 추가(대상 `-j` 필요), `-F` 는 초기화, `-D` 는 삭제 → [[iptables]] · [[network-security]] 2-1.

**20. ②** RSA 는 공개키/개인키 쌍을 쓰는 비대칭키. AES·DES·SEED·ARIA 는 대칭키 알고리즘 → [[network-security]] 4-1 · [[sha256sum]].
