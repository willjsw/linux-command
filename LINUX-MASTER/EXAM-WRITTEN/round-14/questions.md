## 리눅스 실무·시스템의 이해

**1.** Apache License 2.0 의 특징으로 옳은 것은?
- ① 강한 카피레프트로 파생물 소스 공개를 강제한다
- ② 상업적 이용을 금지한다
- ③ 특허 사용 허가 조항을 포함하며 파생물의 비공개 배포가 가능하다
- ④ 소스 코드 배포 자체를 금지한다

**2.** 다음 리눅스 배포판 중 패키지 관리 계열이 다른 하나는?
- ① Fedora
- ② Ubuntu
- ③ openSUSE
- ④ Rocky Linux

**3.** systemd 에서 특정 시각·주기에 작업을 실행하여 cron 을 대체할 수 있는 유닛 유형은?
- ① service
- ② mount
- ③ socket
- ④ timer

**4.** 하드 링크(hard link)에 대한 설명으로 옳은 것은?
- ① 서로 다른 파일시스템 간에 생성할 수 있다
- ② 원본과 동일한 inode 를 공유한다
- ③ 디렉터리에도 자유롭게 생성할 수 있다
- ④ 원본을 삭제하면 즉시 접근이 불가능하다

**5.** 스왑 파티션을 만든 뒤 이를 실제로 활성화하는 명령은?
- ① `mkswap`
- ② `swapon`
- ③ `free`
- ④ `mount`

## 네트워크의 이해

**11.** `172.16.0.0/12` 대역에 대한 IP 클래스·용도의 연결로 옳은 것은?
- ① A 클래스 공인
- ② C 클래스 사설
- ③ D 클래스 멀티캐스트
- ④ B 클래스 사설

**12.** Smurf 공격의 특징으로 옳은 것은?
- ① 브로드캐스트로 ICMP 를 증폭하며 출발지 IP 를 위조한다
- ② SYN 패킷을 대량 전송해 백로그 큐를 고갈시킨다
- ③ 조작된 프래그먼트 오프셋으로 재조합 오류를 유발한다
- ④ 출발지와 목적지를 동일하게 위조한다

**13.** 외부 80번 요청을 내부 `192.168.0.10:8080` 으로 전달하는 포트포워딩에 사용하는 iptables 체인·타깃 조합은?

- ③ PREROUTING 체인 + DNAT
- ④ FORWARD 체인 + REJECT

**14.** 침입 탐지 방식 중 알려지지 않은 새로운(미지의) 공격 탐지에 상대적으로 유리한 것은?

**15.** 티켓 기반 인증으로 KDC 와 TGT 를 사용하는 인증 프로토콜은?
