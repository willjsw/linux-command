## 리눅스 시스템의 이해 — SHELL·프로세스·X 윈도

**6.** bash 에서 명령의 실행 결과를 값으로 치환(command substitution)하는 올바른 표현은?
- ① `$(date)`
- ② `${date}`
- ③ `$[date]`
- ④ `$'date'`

**7.** 표준 출력과 표준 오류를 모두 같은 파일 `out` 으로 보내는 표현으로 옳은 것은?
- ① `cmd > out 2> out`
- ② `cmd > out 2>&1`
- ③ `cmd 2>&1 > out`
- ④ `cmd < out`

**8.** 일반 사용자가 `renice` 로 자신의 프로세스에 대해 수행할 수 있는 작업은?
- ① nice 값을 음수로 낮춰 우선순위를 높인다
- ② 다른 사용자 프로세스의 우선순위를 변경한다
- ③ 자신의 프로세스 nice 값을 높여 우선순위를 낮춘다
- ④ nice 값 범위를 -20~100 으로 확장한다

**9.** cron 작업 정의(crontab)에서 필드 순서로 옳은 것은?
- ① 분 시 일 월 요일
- ② 시 분 일 월 요일
- ③ 요일 월 일 시 분
- ④ 분 시 요일 일 월

**10.** X 클라이언트(응용 프로그램)가 출력을 보낼 X 서버의 위치를 지정하는 환경변수는?

- ③ `PATH`
- ④ `LANG`

## 시스템 관리·장치 관리

**16.** 8진수 `2750` 으로 설정된 디렉터리의 특수 권한과 효과로 옳은 것은?
- ① SetUID — 실행 시 소유자 권한으로 동작
- ② SetGID — 디렉터리 내 생성 파일이 그룹을 상속
- ③ Sticky Bit — 소유자만 파일 삭제 허용
- ④ 일반 권한만 설정됨

**17.** `/etc/shadow` 의 비밀번호 필드가 `!` 또는 `*` 로 시작할 때의 의미는?
- ① 비밀번호 없이 무제한 로그인
- ② 관리자 전용 계정
- ③ 비밀번호 만료 임박
- ④ 계정 잠금(로그인 불가)

**18.** wheel 그룹에 속한 사용자만 `su` 를 사용하도록 제한하는 PAM 모듈은?
- ① `pam_wheel.so`
- ② `pam_securetty.so`
- ③ `pam_tally2.so`
- ④ `pam_cracklib.so`

**19.** RAID 6 을 디스크 6개(각 2TB)로 구성할 때 사용 가능한 총 용량은?
- ① 6TB
- ② 12TB
- ③ 8TB
- ④ 10TB

**20.** TCP Wrapper 에서 `/etc/hosts.allow` 와 `/etc/hosts.deny` 의 검사 순서·우선순위로 옳은 것은?
- ① deny 를 먼저 검사하며 deny 우선
- ② allow 를 먼저 검사하며 allow 우선
- ③ 두 파일 모두 없으면 접속을 거부
- ④ deny 에만 등록되면 allow 를 무시하고 허용
