## 리눅스 실무·시스템의 이해

- ① 리처드 스톨먼 / 1983
- ② 리누스 토르발스 / 1991
- ③ 켄 톰슨 / 1969
- ④ 앤드루 타넨바움 / 1987

**2.** GPL 라이선스의 특징으로 옳지 않은 것은?
- ① 소스 코드 공개 의무
- ② 자유로운 복제·배포 허용

- ④ 소스 비공개 상용 배포 허용

**3.** 다음 중 리눅스 배포판과 패키지 관리 계열의 연결이 옳은 것은?
- ① Debian — rpm
- ② Rocky Linux — dpkg
- ③ Ubuntu — dnf
- ④ CentOS — rpm

**4.** 부팅 과정의 순서로 옳은 것은?

- ④ 커널 → BIOS → 부트로더 → init/systemd

**5.** GRUB2 설정 파일을 재생성하는 명령으로 옳은 것은?

- ② `^^`

**8.** 다음 중 부모 프로세스가 종료되었으나 자식이 계속 실행되어 init 에 입양되는 프로세스는?

- ② 고아(Orphan) 프로세스
- ③ 데몬(Daemon) 프로세스
- ④ 세션 리더

**9.** X 윈도 시스템에서 클라이언트-서버 구조에 대한 설명으로 옳은 것은?

- ③ 반드시 동일 호스트에서만 동작
- ④ 디스플레이 매니저 없이는 실행 불가

**10.** 프로세스 우선순위(NI 값) 조정에 대한 설명으로 옳은 것은?

- ② 값이 낮을수록 우선순위가 낮음
- ③ 일반 사용자는 자신의 프로세스 우선순위를 낮출(양수) 수만 있음
- ④ `renice` 는 실행 중 프로세스에 적용 불가
