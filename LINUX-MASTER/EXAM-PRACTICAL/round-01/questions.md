## 1부. 명령어 작성 (직접 서술)

**1.** 현재 디렉터리 이하에서 확장자가 `.log` 이면서 수정된 지 7일이 지난 파일을 모두 찾아 삭제하는 `find` 명령을 작성하시오.

**3.** `/dev/sdb1` 파티션을 `ext4` 로 포맷한 뒤 `/data` 에 마운트하는 명령 2개를 순서대로 작성하시오.

**4.** 프로세스 이름에 `nginx` 가 포함된 모든 프로세스의 PID 를 조회하는 명령을 작성하시오. (`ps` + 파이프 또는 전용 명령 무관)

**5.** 8080 포트를 LISTEN 중인 프로세스를 확인하는 `ss` 명령을 작성하시오.

## 3부. 설정·개념 서술

**11.** `/etc/crontab` 한 줄이 다음과 같을 때 각 필드의 의미를 서술하시오.
```
0 2 * * 1 root /usr/local/bin/backup.sh
```

**12.** 다음 iptables 명령이 수행하는 동작을 서술하시오.
```
iptables -A INPUT -p tcp --dport 22 -s 192.168.0.0/24 -j ACCEPT
```

**13.** `tar` 로 `/home` 디렉터리를 `home.tar.gz` 로 압축 백업하는 명령과, 각 옵션 문자(c, z, v, f)의 의미를 서술하시오.
