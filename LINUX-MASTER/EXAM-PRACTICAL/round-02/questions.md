## 1부. 명령어 작성 (직접 서술)

**1.** 루트(`/`) 이하 전체에서 SetUID 가 설정된 **일반 파일**을 모두 검색하는 명령을 작성하시오. (침해 점검 단골)

**2.** `/var/www/html` 디렉터리 이하 모든 파일·하위 디렉터리의 소유자와 그룹을 `apache` 로 **재귀 변경**하는 명령을 작성하시오.

**3.** 아카이브 `backup.tar.gz` 를 `/restore` 디렉터리에 풀어(추출) 넣는 명령을 작성하시오.

**4.** 현재 **확립(ESTABLISHED)** 상태인 TCP 연결 목록을 숫자 표기로 조회하는 `ss` 명령을 작성하시오.

**5.** 로컬 디렉터리 `/data` 를 원격 호스트 `user@host` 의 `/backup` 으로 권한·심볼릭링크 보존 및 압축 전송하는 `rsync` 명령을 작성하시오.

## 2부. 빈칸 채우기

## 3부. 설정·개념 서술

**11.** `/etc/shadow` 파일 한 줄이 다음과 같을 때, 콜론으로 구분된 3번째~5번째 필드(`18900`, `0`, `90`)가 각각 무엇을 의미하는지 서술하시오.
```
user1:$6$abc...:18900:0:90:7:::
```

**12.** 다음 iptables 명령이 수행하는 동작을 서술하시오.
```
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
```

**13.** 특수 권한 `SetUID` 와 `SetGID` 의 8진수 값과 각각의 효과(실행 시 어떤 권한으로 동작하는지)를 서술하시오.

**14.** rsyslog 설정에서 다음 두 규칙의 동작 차이를 서술하시오.
```
mail.info    /var/log/maillog
mail.=info   /var/log/mail-only.log
```

**15.** RAID 1 과 RAID 5 의 구성 원리 차이, 각 방식의 **최소 디스크 개수**와 **가용 용량**(디스크 n개, 각 용량 D 기준)을 서술하시오.
