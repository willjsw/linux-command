# 사용자·권한 관리

- 리눅스마스터 1급 필기 대비 이론 — 계정 파일·관리 명령·권한·특수권한·umask·ACL·쿼터
- `/etc/passwd`·`/etc/shadow` 필드 순서와 8진수 권한값이 최빈출 → 필드·숫자 암기 필요

---

## 1. 계정 관련 파일

### 1-1. `/etc/passwd` — 7개 필드 (최빈출)

```
root:x:0:0:root:/root:/bin/bash
    └1  └2 └3└4└5   └6      └7
```

| # | 필드 | 설명 |
| --- | --- | --- |
| 1 | 로그인명 | 사용자 계정 이름 |
| 2 | 비밀번호 | `x` = 실제 암호는 `/etc/shadow` 에 (섀도 사용) |
| 3 | UID | 사용자 ID |
| 4 | GID | 기본 그룹 ID |
| 5 | 설명(GECOS) | 실명·주석 등 (비어도 무방) |
| 6 | 홈 디렉터리 | 로그인 시 이동 경로 |
| 7 | 로그인 셸 | `/bin/bash` 등, `/sbin/nologin` = 로그인 차단 |

- 모든 사용자 읽기 가능(`644`) → 비밀번호를 `x` 로 분리 보관

### 1-2. `/etc/shadow` — 9개 필드

```
root:$6$...암호화...:19700:0:99999:7:::
    └1   └2          └3   └4└5   └6└7└8└9
```

| # | 필드 | 설명 |
| --- | --- | --- |
| 1 | 로그인명 | 계정 이름 |
| 2 | 암호화 비밀번호 | 해시값 / `!`·`*` = 잠금, 빈칸 = 비밀번호 없음 |
| 3 | 최종 변경일 | 마지막 변경일 (1970-01-01 기준 경과 일수) |
| 4 | 최소 사용기간 | 변경 후 재변경 가능까지 최소 일수 |
| 5 | 최대 사용기간 | 비밀번호 유효 최대 일수 |
| 6 | 경고일 | 만료 며칠 전부터 경고 |
| 7 | 비활성일 | 만료 후 계정 비활성까지 유예 일수 |
| 8 | 만료일 | 계정 자체 만료일 (1970 기준 일수) |
| 9 | 예약 | 미사용 예약 필드 |

- 권한 `600` (root 전용) — 유출 시 오프라인 크래킹 대상
- `passwd`·`chage` 로 필드 조작 → [[passwd]]

### 1-3. `/etc/group` — 4개 필드

```
wheel:x:10:user1,user2
     └1 └2 └3 └4
```

| # | 필드 | 설명 |
| --- | --- | --- |
| 1 | 그룹명 | 그룹 이름 |
| 2 | 비밀번호 | `x` = `/etc/gshadow` 에 보관 |
| 3 | GID | 그룹 ID |
| 4 | 구성원 | 이 그룹을 **2차(보조) 그룹**으로 갖는 사용자 목록 |

- 기본(1차) 그룹은 `/etc/passwd` 4번 필드, 보조 그룹이 `/etc/group` 4번 필드

### 1-4. `/etc/gshadow`

- 그룹 비밀번호·그룹 관리자 정보 보관 (`600`)
- 필드: `그룹명:암호화비밀번호:그룹관리자:구성원`

## 2. 사용자·그룹 관리 명령

### 2-1. 사용자 관리

| 명령 | 용도 | 주요 옵션 |
| --- | --- | --- |
| `useradd` | 계정 생성 | `-u`(UID) · `-g`(기본그룹) · `-G`(보조그룹) · `-d`(홈) · `-s`(셸) · `-m`(홈 생성) |
| `usermod` | 계정 수정 | `-L`(잠금) · `-U`(해제) · `-aG`(보조그룹 추가) · `-s`(셸 변경) → [[usermod]] |
| `userdel` | 계정 삭제 | `-r`(홈·메일 스풀까지 삭제) |

- `usermod -aG` 에서 `-a` 누락 시 기존 보조그룹 **덮어쓰기** 주의
- 사용자 확인: `id <계정>` (UID·GID·그룹) → [[id]]

### 2-2. 그룹 관리

| 명령 | 용도 |
| --- | --- |
| `groupadd` | 그룹 생성 (`-g` GID 지정) |
| `groupmod` | 그룹 수정 (`-n` 이름 변경 · `-g` GID 변경) |
| `groupdel` | 그룹 삭제 (기본 그룹으로 쓰는 사용자 존재 시 불가) |

### 2-3. 관련 설정 파일

| 경로 | 용도 |
| --- | --- |
| `/etc/login.defs` | UID/GID 범위·비밀번호 기본 정책(만료·최소길이) 전역 기본값 |
| `/etc/default/useradd` | `useradd` 기본값 (기본 그룹·홈·셸·만료) |
| `/etc/skel` | 신규 홈 디렉터리로 복사되는 **기본 파일 템플릿** (`.bashrc` 등) |

## 3. UID / GID 체계

| 구분 | UID 범위(일반적) | 설명 |
| --- | --- | --- |
| root | `0` | 슈퍼유저 (전권) |
| 시스템 계정 | `1 ~ 999` | 데몬·서비스용 (배포판별 상한 상이, RHEL7+ 기준 1~999) |
| 일반 사용자 | `1000 ~` | `useradd` 로 생성되는 계정 |

- UID 0 = root — UID 가 0 이면 계정명과 무관하게 root 권한
- 시스템/일반 경계값(500 또는 1000)은 배포판·버전따라 상이 → `/etc/login.defs` 의 `UID_MIN` 확인

## 4. 파일 권한

### 4-1. 소유권·권한 구조

- 대상 3주체: **소유자(user) / 그룹(group) / 기타(other)**
- 권한 3종: 읽기 `r` / 쓰기 `w` / 실행 `x`

| 권한 | 문자 | 8진수 |
| --- | --- | --- |
| 읽기 | `r` | 4 |
| 쓰기 | `w` | 2 |
| 실행 | `x` | 1 |
| 없음 | `-` | 0 |

```
-rwxr-xr--   →  744
 └u └g └o
 rwx r-x r--
 421 401 400
 =7  =5  =4
```

- 디렉터리의 `x` = 진입(cd)·하위 접근 권한, `r` = 목록 조회 권한

### 4-2. 권한·소유권 변경 명령

| 명령 | 용도 | 예시 |
| --- | --- | --- |
| `chmod` | 권한 변경 | 숫자 `chmod 755 file` / 기호 `chmod u+x,go-w file` |
| `chown` | 소유자(그룹) 변경 | `chown user1:group1 file` |
| `chgrp` | 그룹만 변경 | `chgrp group1 file` |

- 기호 모드: 대상 `u`/`g`/`o`/`a` + 연산 `+`/`-`/`=` + 권한 `r`/`w`/`x`
  - `chmod a=r file` → 전체를 읽기만(`444`)
  - `chmod o-rwx file` → 기타 권한 전부 제거
- `-R` : 하위 재귀 적용 (`chmod -R 755 dir`)

## 5. 특수 권한 (요약)

| 구분 | 8진수 | 표기 | 효과 |
| --- | --- | --- | --- |
| SetUID | 4000 | `-rwsr-xr-x` | 실행 시 **소유자 권한**으로 동작 |
| SetGID | 2000 | `-rwxr-sr-x` | 실행 시 그룹 권한 / 디렉터리엔 그룹 상속 |
| Sticky Bit | 1000 | `drwxrwxrwt` | 디렉터리 내 파일 삭제를 소유자만 허용 (`/tmp`) |

- 지정: `chmod 4755 file`(SetUID) · `chmod 2755 dir`(SetGID) · `chmod 1777 dir`(Sticky)
- 실행권한 없이 특수권한만 있으면 대문자(`S`·`T`) 표기
- 표기·효과 상세·전수 검색은 → [[system-security]]

## 6. umask

- 새로 생성되는 파일·디렉터리의 **기본 권한 차감 마스크**
- 기준값: 파일 `666`, 디렉터리 `777` 에서 umask 차감

| umask | 파일(666-) | 디렉터리(777-) |
| --- | --- | --- |
| `022` | `644` | `755` |
| `002` | `664` | `775` |
| `077` | `600` | `700` |

- 파일은 실행권한 기본 미부여 → **666 기준** 계산 (777 아님)이 함정
- 확인·설정: `umask` (조회) / `umask 022` (설정)
- 계산은 단순 뺄셈이 아닌 비트 마스킹이나, 시험 범위에선 자릿수 차감으로 계산 가능

## 7. ACL (Access Control List)

- 기본 3주체(user/group/other) 권한을 넘어 **특정 사용자·그룹별 세밀 제어**
- `setfacl` : ACL 설정 / `getfacl` : ACL 조회

```
setfacl -m u:user2:rw file      # user2 에게 rw 부여
setfacl -m g:group2:r file      # group2 에게 r 부여
setfacl -x u:user2 file         # user2 항목 제거
setfacl -b file                 # ACL 전체 제거
getfacl file                    # ACL 조회
```

- ACL 적용 파일은 `ls -l` 권한열 끝에 `+` 표시 (`-rw-r--r--+`)
- 기본(default) ACL: 디렉터리에 `-d` 로 지정 → 하위 생성 파일에 상속

## 8. 디스크 쿼터 (Quota)

- 사용자·그룹별 **디스크 사용량·파일(inode) 개수 제한**
- 제한 단위 2종

| 구분 | 의미 |
| --- | --- |
| 블록(block) 제한 | 사용 **용량** 제한 |
| inode 제한 | 생성 가능 **파일 개수** 제한 |

- 한계 2단계

| 구분 | 동작 |
| --- | --- |
| soft limit | 초과 허용하되 **경고**, grace period 내 조정 필요 |
| hard limit | **절대 상한** — 초과 즉시 차단 |
| grace period | soft 초과 후 hard 로 강제되기까지의 유예 기간 |

- 관련 명령(개념): `quota`(사용량 조회) · `edquota`(사용자별 편집) · `quotacheck`(파일시스템 검사) · `repquota`(요약 보고) · `quotaon`/`quotaoff`(활성·비활성)
- 활성화: 마운트 옵션 `usrquota`(사용자)·`grpquota`(그룹)를 `/etc/fstab` 에 지정
